# SafeLoot on CurseForge: what goes in each field

- **Name:** SafeLoot
- **Summary:** `summary.txt` (215 characters)
- **Description:** `description.html` (paste in the editor's source view; English first, Spanish below)
- **Logo:** `art/logo/logo-400.png` (or `logo-1024.png`)
- **Categories:** main "Bags & Inventory" or "Boss Encounters" are not right: use the one for loot or chat ("Miscellaneous" if there is none), then Chat & Communication, Guild, Tooltip
- **Licence:** GNU GPL version 2 for the download as a whole, because the zip includes `SafeLoot_LootData` (GPL-2.0). SafeLoot's own code is MIT, which the description says
- **Source:** https://github.com/FomoDonkey/SafeLoot
- **Issues:** https://github.com/FomoDonkey/SafeLoot/issues
- **File:** `dist/SafeLoot-<version>.zip` (made by `python tools/package.py`)
- **Game version:** WoW Forever, 1.60.1. Only Forever
- **Release type:** Beta until boss loot and the alarm have been seen inside a dungeon
- **Changelog:** the section of that version in `CHANGELOG.md`
- **Screenshots:** real ones, taken in the game, without other players' names
