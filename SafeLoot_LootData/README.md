# SafeLoot: loot data

Boss loot tables for [SafeLoot](https://github.com/FomoDonkey/SafeLoot), as a separate, optional add-on.

- **Source:** derived from [AtlasLoot Classic Forever](https://www.curseforge.com/wow/addons/atlasloot-forever) 1.4.9 by
  sliccer, a fork of [AtlasLootClassic](https://github.com/Hoizame/AtlasLootClassic) by Hoizame and contributors
  (`AtlasLootClassic_DungeonsAndRaids/data.lua`), licensed under the GNU GPL version 2.
- **License of this folder:** GNU GPL version 2 (see `LICENSE`). SafeLoot itself, in the parent folder, is MIT.
- **Changes made (November 2026):** only the item IDs per boss were kept; the bosses were matched with the encounter IDs
  of the WoW: Forever client; keys and items below uncommon quality were left out; IDs the Forever client does not have
  were dropped. `Data.lua` is generated by `tools/gen_lootpack.py`.
- **What it does not say:** loot can change with any patch. SafeLoot marks every item as "not seen yet" until it has
  really been seen dropping.
